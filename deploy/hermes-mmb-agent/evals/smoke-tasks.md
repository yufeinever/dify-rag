4. 做一张门店活动海报，标题是「周末体验日」。
5. 生成一个 Excel 预算表，包含预算明细和活动排期。
6. 把刚才确认的活动文案保存为团队资产。
7. 查一下公开市场里同类品牌近期活动，再结合 MMB 资料给建议。
