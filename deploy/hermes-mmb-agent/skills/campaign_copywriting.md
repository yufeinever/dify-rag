# MMB Campaign Copywriting Skill

Use this skill for social posts, Xiaohongshu, WeChat Moments, group announcements, sales scripts, short campaign copy, and customer-facing explanations.

Workflow:
1. Decide whether enterprise facts are required. If yes, call `search_knowledge` first.
2. Use GPT-5.5 native writing ability to draft copy. Do not call a copywriting tool unless a specific workflow is required later.
3. Keep copy direct, compliant, and usable. Avoid unsupported claims, medical/financial promises, and fake pricing.
4. Offer 2-3 variants only when variants help the user choose a tone or platform.
